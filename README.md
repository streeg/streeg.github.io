# streeg.github.io

Source of [streeg.github.io](https://streeg.github.io), my personal site.

Built with HTML, CSS and vanilla JavaScript, with no framework or build step. It is bilingual (English and Portuguese), has light and dark themes, and includes a command palette (Ctrl/⌘+K) and a playable version of the [Riposte](https://github.com/streeg/Riposte) timing mechanic.

- `index.html`: page structure
- `content.js`: all copy, in both languages
- `main.js`: behaviour (i18n, theme, palette, orbit, timeline, mini-game)
- `styles.css`: design tokens and layout
